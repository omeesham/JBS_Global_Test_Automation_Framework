## Context

The full 13-spec Encore suite needs to be run from a completely clean state — zero contamination from previous runs — and produce two fresh, viewable reports:
1. **Playwright HTML report** at `reports/html-report/index.html`
2. **Allure report** at `reports/allure-report/index.html`

The user wants 1 worker and the Chromium project (authenticated). No Allure trend history required — latest run results only.

**Why this plan exists**: The working directory (`clients/encore/`) has stale artifacts from a May 11 run (64 old `allure-results/` files, an existing `html-report/`, leftover `test-results/`). A naive `npm test` would append to these. The correct sequence wipes all stale state first, then runs clean, then generates both reports.

**Critical project note**: There are two Chrome-like projects in `playwright.config.ts`:
- `chrome` — uses real Google Chrome binary, **no auth setup**, no `storageState`. Running `--project=chrome` will fail on login.
- `chromium` — uses bundled Chromium, has `dependencies: ['setup']` + `storageState: '.auth/encore-state.json'`. This is the authenticated project used for suite runs.

The `setup` project (`/auth.setup.ts`) runs automatically as a dependency of `chromium`. Do not specify `--project=setup` separately.

### Phase 2 — Clean report outputs only (zero contamination, nothing important lost)

Removes ONLY the stale report outputs — no diagnostics, no archive, no logs, no bugs, no rca data.

```powershell
npm run clean:reports
```

**What `clean:reports` removes** (exact paths from package.json):
- `reports/html-report/` — old Playwright HTML report
- `reports/allure-results/` — old Allure test result JSONs
- `reports/allure-report/` — old generated Allure report
- `reports/test-results/` — old Playwright trace/screenshot/video artifacts
- `reports/test-results.json` — old Playwright JSON summary
- `reports/failure-summary.json` — regenerated by the new run
- `reports/junit-results.xml` — old JUnit XML

Then `ensure-report-dirs.js` recreates empty dirs:
- `reports/allure-results/`
- `reports/html-report/`
- `reports/test-results/`
- `reports/diagnostics/`

**NOT touched (preserved):**
- `reports/allure-archive/` — historical run archives with trend data
- `reports/diagnostics/` — diagnostic artifacts
- `reports/walkthrough/` — walkthrough artifacts
- `reports/bugs/` — filed bug reports
- `reports/rca/` — RCA artifacts
- `logs/` — test execution logs
- `.auth/encore-state.json` — auth session (must not be touched)

**Verify clean succeeded**: after `npm run clean:reports`, these must NOT exist:
- `reports/allure-results/*.json` (result files — empty dir is OK)
- `reports/html-report/index.html`
- `reports/test-results.json`

### Phase 3 — Run full suite (1 worker, Chromium project)

```powershell
npx playwright test --config=playwright.config.ts --project=chromium --workers=1
```

**What this runs**:
- `setup` project first (auth — acquires/refreshes `.auth/encore-state.json`)
- Then all 13 specs under `specs/` via `chromium` project
- 1 worker — specs run sequentially
- Reporters write to: `reports/html-report/`, `reports/allure-results/`, `reports/test-results/`, `reports/test-results.json`, `reports/junit-results.xml`

**Expected console output** starts with:
```
Running X tests using 1 worker
```

**Do NOT use `--project=chrome`** — that project has no `storageState` and no `dependencies: ['setup']`, so all tests would fail on authentication.

**Retries**: config sets `retries: 1` locally (non-CI). Each failing test gets 1 retry.

**Expected duration**: ~60–120 min at 1 worker for 13 specs (timing depends on test count per spec).

### Phase 4 — Generate Allure report

The HTML report is auto-generated by `playwright test` (reporter writes directly to `reports/html-report/`). Allure requires a separate generation step:

```powershell
npm run allure:generate
```

This runs:
```
npx allure generate reports/allure-results --clean -o reports/allure-report
```

**Verify**: `reports/allure-report/index.html` must exist after this step. If `allure:generate` exits non-zero, check that `reports/allure-results/` has `*-result.json` files (at least one per test).

### Phase 5 — Open reports

Open HTML report (Playwright built-in):
```powershell
npm run report
```
Opens `reports/html-report/index.html` at `http://localhost:<port>`.

Open Allure report:
```powershell
npm run allure:open
```
Opens `reports/allure-report/index.html` in browser.

Both commands launch a local server. They can be run simultaneously in separate terminals.

## Known limitations / gotchas

| Issue | Detail |
|---|---|
| `chrome` project | No auth. Never use `--project=chrome` for suite runs. |
| Workers override | `--workers=1` CLI flag overrides the config `workers: 2` (local default). Alternatively: `$env:MAX_WORKERS="1"; npx playwright test ...` |
| Auth expiry | If `global-setup` fails (auth expired), run `npx playwright test --project=setup` in a headed window to refresh `.auth/encore-state.json`, then re-run Phase 3. |
