## Tasks (Option B — auto-regen)

1. **Design `npm run plans:reindex` script** (`scripts/plans-reindex.mjs`):
   - Walk `plans/pending/` and `plans/done/`
   - For each `.md` file:
     - Extract `Status` field (regex)
     - Extract `Created` / `Executed` dates
     - Extract `Priority`
     - Extract title (first `# ` line)
     - Extract `Parent` if present (subplan)
   - Group by directory (pending vs done)
   - Group subplans under their parent
   - Output structured INDEX.md with:
     - Header: `**Last updated**: <today via `new Date().toISOString().slice(0,10)`>`
     - Pending section (table)
     - Done section (table, sorted by Executed date desc)
     - Subplan tree visualization (parent → children)
     - Stale warning section (any pending file older than 14 days flagged)
     - DONE-but-not-moved warning section (Status: DONE in pending/)
2. **Add to `package.json` scripts**:
   ```json
   "plans:reindex": "node scripts/plans-reindex.mjs"
   ```
3. **Add a hook** (one of):
   - Pre-commit hook: regen + git-add INDEX.md
   - npm postinstall: reminder to run
   - Activity log gate: regen on every pipeline session start
4. **First regen + commit**:
   - Run `npm run plans:reindex`
   - Diff against current INDEX → review
   - Commit: `chore(plans): auto-regenerate INDEX from filesystem state`
5. **Update CLAUDE.md** with note: "INDEX.md is auto-generated by `npm run plans:reindex` — do not hand-edit"
