# Preference pattern learning

**Rule**: Same preference, directive, or correction repeated 3+ times across sessions = pattern. Capture once to a `feedback_<topic>.md` file. One rule, one why, one how-to-apply. No flourishes.

**Why**: He said directly — "if i tell u one thing multiple times (3 or more) its a pattern u have to note in a very /slop free way, minimal but effective." Making him teach the same lesson a fourth time is a discipline failure, not an honest mistake.

**How to apply**:
- On each repeat, count it (cross-session — use existing memory as the tally).
- At the third repeat, pause, author one minimal memory file. Update `MEMORY.md` with one line.
- Never duplicate an existing pattern — refine the existing memory if nuance shifts; don't spawn a new file for the same rule.
- Slop-free: fits in 10 lines, stays at 10 lines. No headers for headers. No rationale paragraphs when one sentence works.
