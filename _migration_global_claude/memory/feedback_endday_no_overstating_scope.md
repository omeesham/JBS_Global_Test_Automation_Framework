**Rule**: Match the verb and scope to the actual state of the work. Never say "updated across all X" when only a subset was touched, OR when a larger initiative (pivot / migration / catalog) just started.

**Why**: If Day N reports "updated test cases and plans across all local office and locations modules" and Day N+5 reports are still showing "continuing pivot work on Local Office Basic Info" — the client reads that as "you said it was done 5 days ago, why are you still on it?". Inconsistency = raises eyebrows = trust damage.

**How to apply**:
- Starting a pivot/migration → "started planning for X pivot" or "reviewed requirements for X pivot approach"
- Mid-pivot touching 1-2 modules → name them: "working on Local Office Basic Info catalog for pivot"
- Only at actual end of initiative → "completed X pivot across locations modules"
- File mtime on 20 files ≠ "worked on all 20" — check if it was a sweep edit vs real engagement

**Self-check before composing**: "If client reads this today, and then reads 5 more days of end-day reports, does today's line make those future lines look like backtracking?" If yes → soften scope.

**Trigger**: Any line with "across all", "all modules", "every module", "finished X module set", or past-tense completion verbs on multi-day initiatives.
