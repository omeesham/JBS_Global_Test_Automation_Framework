Rutvik (2026-07-12, PLAN_UPLINK_PROTOCOL steering): "the 5 pipeline agents are the skins, copilot agents take a skin, take its responsibilities, does the job properly and gets shit done… the pipeline agents are no diff from other agents… they work on encore, rest work everywhere."

**Why:** Designing chain mechanisms (uplink, escalation, review) per agent-TYPE creates phantom "separate waves" for pipeline agents. The correct model: three functions per chain position — worker / supervisor (dumb code) / oracle ladder — and whoever occupies the position gets the mechanism, whatever skin (identity) it wears.

**How to apply:** When planning any cross-agent mechanism, ask "which chain position does this attach to?" never "which agent type gets this?". Pipeline-identity sessions running inline in Claude get the Claude-tier mechanism (oracle = Rutvik); copilot workers wearing a skin get the worker-tier mechanism (oracle = Claude).
