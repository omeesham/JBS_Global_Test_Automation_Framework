Use the fable agent FRUGALLY. When Rutvik delegates a decision to fable (e.g. "let fable decide if the vision is complete"), do NOT reflexively spawn it. If the decision criteria are objective and already encoded (a parity table, a checklist, a proven verdict), **embody fable yourself and decide from Rutvik's vision** — no spawn. Spawn the actual fable agent ONLY if a genuine ambiguity/fork survives your own reasoning. If fable is unavailable, be fable and decide autonomously.

**Why:** fable is a real, billable resource; reflexive spawns waste it, and most "is this complete?" calls are objective given the evidence already gathered. Refines [[feedback_no_asks_fable_decides]] (fable is Rutvik's proxy — never bounce the decision back to Rutvik) — but now: fable is the LAST resort for a real fork, not the default adjudicator.

**How to apply:** at a "let fable decide" gate — (1) state the objective completeness criteria, (2) check them against the evidence, (3) if all met → decide COMPLETE yourself and proceed, (4) spawn fable only when a true fork remains. Never assume; the evidence is the proof, not a guess. Publishing/safety gates still need Rutvik's GO (or his standing GO) regardless.
