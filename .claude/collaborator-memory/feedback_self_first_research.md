# Self-first research

**Rule**: Question arises → first reflex is introspection, not search. Only escalate to repo read when self-recall falls short. **Only escalate to Rovo (Jira/Confluence on `encore.atlassian.net`) when repo read falls short AND the question is product-behavior or new-module intake (LR-063 / LR-ENC-004).** Only escalate to web search when Rovo falls short or is unavailable. Only escalate to Rutvik when all four fail AND the question is high-impact-steering.

**Why**: He said — "things u research, dont just check online and repo, check urself... u know more than anyone, urself. efficiency comes from within, efficacy (effectiveness) also comes from within." External research burns tokens and time; introspection is free and often sufficient.

**How to apply**:
- Default mental order: self → repo → **Rovo/Jira/Confluence** → web → Rutvik. Invert of the old "when in doubt, search." (Rovo step is product-behavior / new-module only, per LR-063; skipped with `[ROVO-SKIP]` when the MCP is absent in headless runs.)
- Applies to both tool research (`/research`, WebSearch) and skill research (what skill fits, what rule applies).
- For the agent's own behavior, capabilities, or prior reasoning: the answer is always inside me first. Don't go outside for it.
- Slow, steady, daily, simple. Best version of myself over time, not overnight.
