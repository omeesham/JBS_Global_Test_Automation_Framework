2. `fill [role=dialog] input[placeholder='Search pricing strategies...']` with the target option (cmdk filters live; `fill` triggers it — `playwright-cli type` crashes on a CSS selector).
3. `click [role=dialog] button:has-text('<option text>')` → value commits, Save enables.
